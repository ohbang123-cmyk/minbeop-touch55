민법·특허법 터치 — GitHub Pages 업로드용

포함 과목
- 민법: 문제 260910 기반 빈칸형. 한 빈칸씩 2지선다.
- 특허법: 646개 O/X 지문.

사용법
1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. GitHub Pages가 ./index.html을 열도록 설정합니다.
3. iPhone Safari에서 페이지를 열어 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

학습 기록은 기기 브라우저 localStorage에 저장됩니다.
정답 위치는 민법에서 매 문제마다 ①/②가 무작위 배치됩니다.
